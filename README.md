# 切土丁張設置ゲーム — 計算＋丁張組立

## 起動

index.htmlをブラウザで開いてください。npm・ネット接続・サーバーは不要です。初級・中級・上級各3問を維持しています。

## 操作の流れ

前半の計算問題は2問です。「幅杭位置の計画法面高」「現況地盤と計画法面の高低差」は出題しません。

1. 法尻位置を求める
2. 幅杭から法尻までの水平距離を求める
3. 「丁張杭を打つ」→地盤をクリック・タップ。2本設置して確定
4. 「水平板を取り付ける」
5. 水平板を上下へマウス・タッチドラッグ。±0.01mボタンも使用可能。「この高さに決定」
6. 設定した水平板ELにおける切出し位置Xを入力
7. 幅杭から法板取付点までの距離を入力。切土側／外側も表示
8. 水平板をクリック・タップして法板取付点を設置。±0.01m／±0.001mの4ボタンで微調整して判定
9. 「法板を取り付ける」
10. 1:nのnを入力。傾きがリアルタイムに変化。確定
11. 「丁張完成判定」

左右両側の問題では、左側・右側を順に組み立て、両側が完成した時点で問題クリアです。小段・勾配変更問題の取付点は最終区間にあるため、その区間の法勾配を設定します。
## 水平板EL

ランダム設定・固定正解は削除しました。水平板はプレイヤーが操作し、近傍の現況地盤高+0.10～0.50mを正解とします。近傍地盤高は、内部で地盤と設計法面の接続位置から求めています。この交点座標・交点式は問題として出題しません。

操作は0.01m刻み。許容範囲の判定には丸め前の値を使用します。例えば範囲13.100～13.500mなら、13.200・13.350・13.500mなどが正解です。水平板が杭位置の地盤に埋まる場合は、高さを上げるか杭を置き直すよう案内します。

確定後はドラッグを無効にし、選んだboardELから以降の答えを算出します。「この側を組み直す」で杭・水平板EL・後半の解答・点・法板を初期化します。「この問題をリセット」は前半を含め初期化します。

## 動的計算

単純法面ではΔEL=boardEL−toeEL、ΔX=ΔEL×n、右側X=toeX+ΔX、左側X=toeX−ΔXです。
小段・勾配変更では区間開始点を順に計算し、板ELを含む区間開始点から同じ式を適用します。
幅杭からの距離はabs(widthStakeX−cutPointX)。左右の向きを使って「幅杭から切土側へ○m」または「外側へ○m」と表示します。

指定例：法尻(5,10)、1:1.5、幅杭X=10.5、板EL13.4 → ΔEL3.4、ΔX5.1、切出しX10.1、距離0.4m（切土側）。自動テストで一致を確認しています。

## 幅杭・既存問題の変更

9問の地盤・掘削高・幅員・法勾配・小段条件は維持しています。幅杭は今回の指示に従って、地盤上の切出し付近から外側へ2m以内へ再配置しました。内部では最終法勾配nに対して外側距離min(2,0.5n+0.5)を問題生成用に使い、許容板ELの範囲で切出し点より外側になります。これは固定の現場ルールではありません。

| 問題 | 幅杭X（m） |
|---|---:|
| 初級1 | 10.750 |
| 初級2 | 8.250 |
| 初級3 | 11.500 |
| 中級1 | 16.250 |
| 中級2 | 9.182 |
| 中級3 | 20.071 |
| 上級1 左／右 | -10.500 / 14.250 |
| 上級2 | 15.250 |
| 上級3 | 14.250 |

これに伴い、前半の幅杭と法尻の水平距離も自動で変わります。右上がり地盤も元の地盤点からそのまま延長します。

## 杭設置の教材用判定

実務寸法が未指定のため、以下はゲーム操作のための判定としてUIにも明記しています。

- 幅杭・板の取付範囲付近の色付きエリア内なら任意のXを選択可能
- エリアは内部基準位置、幅杭、許容最大板ELの位置を含む範囲に余白を付ける
- 2本の間隔は基準範囲幅の8%以上（画面上で区別し、2本として扱うため）
- 板は2本の杭をまたぎ、許容ELの取付点を含める長さで描画
- 板は両杭の地盤より上にあること

設置位置を唯一の正解にしていません。描画上の杭高・板長・張出しは操作用の表現で、現場の寸法や構造安全性を規定しません。

## 点・完成判定

点の判定：絶対X誤差0.03m以内＝正解、0.10m以内＝ほぼ正解、それ以外＝再調整。「ほぼ正解」では次へ進まず微調整します。
法板はプレイヤーが置いた点を通り、入力されたnで傾きます。未入力では取付位置だけを示し、角度は表示しません。

完成には、杭2本・板設置・有効な板ELの確定・切出し位置と距離の正解・点の精度・法板設置・正しい法勾配がすべて必要です。単にクイズを解くだけではクリアになりません。
完成図は、設置した杭・板・点・法板をそのまま残します。表示する点までの距離はプレイヤーの実際の点座標から算出します。

## 配点・進捗

前半2STEPは各20点、計40点。後半はSTEP3～10が5/5/10/10/10/10/5/5点、計60点。左右問題は後半60点を左右で等分します。完成判定で全条件を満たして100点・クリアです。
クリア履歴はlocalStorageのcut-slope-progress-assembly-v1に保存。旧計算クイズの履歴は削除せず、今回の組立版とは区別しています。途中の組立は保存しません。

## 検証と制限

計算テストは全9問、指定例、左右、小段・勾配変更、複数の許容板EL、外側2m以内の幅杭、点の境界精度、複数の杭位置、各完成必須条件を確認します。
ブラウザ検証は隣のcut-slope-verification/browser-test.cjsにあります。PCは全9問を実マウス入力で操作し、スマートフォン相当のタッチイベントも確認します。ゲーム起動にテスト用ライブラリは不要です。
実機スマートフォン・全ブラウザの網羅検証、実務的な構造安全性の検証は行っていません。教材の設置判定を現場の基準として使わないでください。


STEP8の点はクリック時から1mm単位へ正規化します。微調整は整数mmに±10または±1を加減し、小数誤差の蓄積を防ぎます。表示・判定には同じ小数第3位の座標を使います。板端では板内のmm格子位置に制限します。


## スマートフォンのピンチ操作

組立SVGはtouch-action:pinch-zoomを使用します。1本指の上下移動をブラウザのページスクロールに渡さず水平板操作に使い、2本指のピンチはブラウザ標準に任せます。viewportにはズーム禁止指定を入れていません。
杭・点のタッチ設置は指を離した時に確定します。2本目の指が入ると設置候補を破棄し、板のドラッグを停止して開始時の高さに戻します。全指が離れるまでゲーム操作を再開しません。ゲーム図のpointerdown/moveではpreventDefaultを呼びません。マウスの設置操作は従来どおりです。

検証：pinch-test.cjsでSTEP3/5/8の2本指入力と誤設置防止、1本指の杭タップ・板ドラッグ・点タップを確認します。ヘッドレスEdgeでは通常ページの比較テストでもvisualViewport.scaleが変わらないため、実際のピンチ拡大縮小倍率は未検証です。実機ブラウザでの確認が必要です。
